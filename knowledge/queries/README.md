# Saved knowledge queries

Keep a query only when its answer is reusable and not already captured by one
concept or synthesis page.

- Use a descriptive kebab-case filename.
- Start with the question and retrieval date.
- Link every material claim to a public knowledge, documentation, or source
  page.
- Record unresolved points explicitly.
- Move general conclusions into the owning maintained page and keep the query
  as a short decision record.

Do not save raw prompts, chat transcripts, private paths, third-party context,
or diagnostic payloads.
