# External source snapshots

This directory is reserved for reviewed, immutable snapshots of public sources
that have no stable in-repository home, such as a model card or specification.

- Record the original URL, author or publisher, retrieval date, and applicable
  license or redistribution basis.
- Preserve the snapshot; add a new dated file instead of silently rewriting it.
- Cite the snapshot from a concept or synthesis page rather than treating it as
  a maintained conclusion.
- Do not duplicate RhinoForge source or documentation here.
- Do not add restricted, credential-bearing, private-project, or diagnostic
  material.

Prefer a direct public link when a local snapshot adds no offline or provenance
value.
